# Screenshot and Evidence Guide

Store only sanitized evidence in this folder.

## Suggested Files

- `01-authentication.png`
- `02-player-dashboard.png`
- `03-character-list.png`
- `04-character-sheet.png`
- `05-class-skill-tree.png`
- `06-dice-roller.png`
- `07-mobile-layout.png`
- `08-test-execution.png`

## Rules

- Do not expose real email addresses, passwords, tokens, IDs, or recovery links;
- Do not expose private player or character information;
- Use dedicated test accounts and fictional characters;
- Crop browser extensions, bookmarks, and unrelated tabs when necessary;
- Record the related test case ID in the commit message or evidence caption;
- Prefer PNG for screenshots and MP4/WebM for short demonstrations;
- Add the browser, operating system, device, date, and application version to the execution record.
